# 🎓 Udemy Homepage UI Clone

A pixel-perfect, responsive frontend clone of the **Udemy homepage** built from scratch using pure **HTML5** and **CSS3**. I created this project to master advanced UI layouts, absolute-positioning layers, and modern semantic web styling.

## ✨ Features

- **Floating Banner Layout**: Features the iconic promotional absolute-positioned card floating seamlessly over the hero imagery.
- **Clean Typography**: Mimics Udemy’s specific font presentation, visual sizing scale, and line hierarchies.
- **Semantic Structure**: Built completely out of accessible HTML5 semantic containers (`<nav>`, `<main>`, `<section>`).
- **Pure Styles**: 100% custom CSS code without relying on bulky third-party frontend utility frameworks.

---

## 🛠️ Tech Stack

- **HTML5** — Layout architecture and core markup
- **CSS3** — Custom properties, CSS Flexbox, and absolute layer positioning

---

## 📝 Learning Outcomes

Building this project helped me strengthen my understanding of:
1. **Absolute vs. Relative Positioning**: Overlapping text content precisely over dynamic graphics banners without breaking standard layout boundaries.
2. **Component Isolation**: Designing independent, modular components that replicate professional, industry-standard learning platforms.
